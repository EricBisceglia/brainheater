# Brain Heater

A remake of a game I used to scribble on notebooks as a kid while bored in class.

Made a Flash implementation of Brain Heater back in 2006.

Twenty years later I felt like bringing it to the browser, and adding new levels and mechanics :)

## Try it out

You can [play it on The Bad Website](https://thebad.website/games/brainheater/).

You can also download this repo then open `index.html` in your browser.

There's nothing to build or install, it will work right away.

## About

Vanilla HTML, JS, CSS, no dependencies, because why not.

Built for [The Bad Website](https://thebad.website/).
