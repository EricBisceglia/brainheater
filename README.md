# Brain Heater

A browser implementation of a game I used to scribble on notebooks as a kid while bored in class.

Made a few Flash implementations of the game in 2006, twenty years later I felt like reworking it for modern interfaces.

Vanilla HTML, JS, CSS, with my own art.

Built for [The Bad Website](https://thebad.website/).

## Try it out

Download this repo then open `index.html` in your browser :)

There's no build or dependencies, it will work right away
